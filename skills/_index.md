# Telos Kernel Skills

系统内核定义，控制 Telos 的核心行为。这些文件采用声明式配置，修改后无需重新编译即可生效（重启应用后生效）。

## 内核文件

- **[intent-matching](_kernel/intent-matching.md)** — 用户意图识别与暗号匹配规则
  - 定义所有可触发动作的短语列表
  - 区分精确匹配与模糊匹配
  - 定义软提示信号和纠正信号
  
- **[interaction](_kernel/interaction.md)** — 交互协议与确认流程
  - 各模式的确认流程定义
  - 向导步骤定义
  - 输入框提示文本
  - 快捷键映射

- **[system](_kernel/system.md)** — 系统核心行为与架构
  - 内核加载顺序
  - 降级策略
  - 版本兼容性
  - 扩展点指南

## 自定义扩展

如需修改系统行为，直接编辑上述文件即可。遵循以下原则：

1. **保持格式**: 遵循 Markdown + YAML frontmatter 格式
2. **备份原文件**: 修改前复制一份备份
3. **逐步验证**: 每次只修改一处，验证后再继续
4. **参考文档**: 详细说明见各文件的注释部分

## 恢复默认

如需恢复内置默认值，删除或重命名 `skills/_kernel/` 目录，系统会自动使用编译时内置的默认规则。
