# Intent Matching Rules

## 规则引擎说明

本文件定义了 Telos 的所有意图匹配规则。系统启动时加载此文件，将用户输入与规则匹配以触发相应动作。

规则分为三类：
- **精确匹配 (exact)**: 用户输入包含任一精确短语即触发
- **模糊匹配 (fuzzy)**: 用户输入包含任一模糊短语，系统先询问确认再触发
- **组合匹配 (composite)**: 用户输入同时包含指定列表中的所有关键词时触发（无需连续，顺序无关）

## 软提示信号 (Soft Signals)

以下短语表示用户认为对话内容有价值，系统应提示保存：

- "这个方法挺好"
- "学到了"
- "记住了"
- "明白了"
- "这个思路不错"
- "原来如此"
- "受教了"
- "mark一下"
- "码住"
- "涨知识了"
- "挺有用的"
- "很实用"
- "不错的方法"
- "好方法"
- "这个技巧不错"

## 纠正信号 (Correction Signals)

以下短语表示用户在纠正或补充技能内容，触发 mini-distillation：

- "纠正"
- "你漏掉"
- "漏掉"
- "补充"
- "修正"
- "应该"
- "下次"
- "记住"
- "wrong"
- "missed"

## 自定义扩展

用户可通过 `~/.config/telos/codewords.json` 添加自定义别名：

```json
{
  "save_skill": ["码住", "收好"],
  "list_skills": ["翻翻看"],
  "create_skill": ["整一个"]
}
```

自定义别名与内置规则合并，自定义别名优先级更高。
